Personal document connection

Jeffrey Local AI Workspace

A personal utility operated by Jeff Frederick that connects authorized local AI applications to Google Drive, Docs, Sheets and Slides.

The connector can find and read files, create and edit documents, spreadsheets and presentations, and manage files when the account owner requests those actions. Google sign-in and consent control which account and permissions are connected.

How the connection works

The connector runs on the owner’s computer. It uses Google’s APIs to carry out requests from configured AI applications. Content requested by an AI application may be processed by that application’s provider. This website is informational and does not sign you in, access Google files or run the connector.

Personal use

This is a personally administered utility, not a public hosted document service. Publishing this information page does not make any Google file public or grant visitors access to the owner’s account.

Read the privacy notice for data access, storage and processing details, and use and support information for controls and limitations.
